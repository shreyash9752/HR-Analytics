# 🧩 HR Analytics Dashboard (Power BI Project)

## 📘 Overview
The **HR Analytics Dashboard** project focuses on analyzing employee data to uncover insights into workforce behavior, attrition trends, and performance metrics. The goal is to help HR departments make data-driven decisions that improve employee retention, engagement, and organizational efficiency.

This interactive **Power BI dashboard** allows users to visualize and explore HR data dynamically — enabling a deeper understanding of key factors influencing attrition, job satisfaction, and work-life balance.

---

## 🧠 Objective
To analyze HR data and provide actionable insights that help organizations:
- Identify factors contributing to employee attrition  
- Monitor employee satisfaction and engagement  
- Evaluate departmental and role-based performance metrics  
- Enhance decision-making with interactive visualizations  

---

## 📊 Key Features
- 🔍 **Attrition Analysis:** Identify trends and patterns in employee turnover  
- 🏢 **Department & Role-Based Insights:** Understand performance across departments and job roles  
- 😊 **Employee Satisfaction & Work-Life Balance Metrics:** Assess key HR indicators for well-being and engagement  
- 📈 **Dynamic & Interactive Visuals:** Explore KPIs through filters and slicers in Power BI  

---

## 🗂️ Dataset Description
The dataset contains **38 columns** with detailed employee information, including:
| Attribute | Description |
|------------|-------------|
| **Age** | Employee age |
| **Business Travel** | Frequency of business trips |
| **Department** | Department where the employee works |
| **Education Field** | Educational background of the employee |
| **Job Role** | Employee’s role in the organization |
| **Job Satisfaction** | Level of satisfaction with the job |
| **Work-Life Balance** | Rating of balance between work and personal life |
| **Attrition** | Indicates whether an employee has left the company |
| **Monthly Income** | Employee’s salary |
| **Years at Company** | Tenure within the organization |

---

## 🛠️ Tools & Technologies
- **Data Visualization:** Power BI  
- **Data Cleaning & Preparation:** Microsoft Excel / Power Query  
- **Dataset:** HR employee data (CSV format)  

---

## 📈 Dashboard Insights
The Power BI dashboard enables users to:
- Track **attrition rate** by department, gender, and age group  
- Visualize **average income distribution** and job satisfaction levels  
- Compare **education field** with attrition and performance metrics  
- Assess the **impact of work-life balance** on employee retention
